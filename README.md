# Curl Babes Website

A responsive hair salon website for **Curl Babes** in Paramaribo, Suriname — owned by Yenell Calor. Built with plain HTML, CSS, and JavaScript.

## Deploy on Vercel

1. Push this repo to GitHub.
2. Go to [vercel.com](https://vercel.com) and import the repository.
3. No build settings needed — Vercel will serve the static files as-is.

## Portfolio Images

Photos live in `/curl-babes-assets/` — client work in `clients/`, salon shots in `salon images/`. Update paths in `index.html` if you add new files.

## Local Preview

Open `index.html` in a browser, or run a simple local server:

```bash
npx serve .
```
